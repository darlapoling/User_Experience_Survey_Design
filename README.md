To take the survey, click the link above and answer the questions based off of the latest hike you've taken (or walk if you don't hike).

This is a project I have constructed to practice and demonstrate my skills for experimental design, specifically survey design. The survey will be on user experience for a specific fictional trail, based off of the trail design guidelines set out by American Trails, a partner of the Forest Service in the US.


During this project, I practiced my skills:
- Implementing principles of experimental design including accounting for sources of bias and non-response
- Qualitatively analyzing sources of bias and reasons for non-response
- Aligning data types with questions for data collection, including the Likert scale for questions on perception and attitudes

Using the following tools and techniques:
- Microsoft Forms
- Markdown
